# Mechatronics 2026 Projects

This repository contains selected MECH 488 mechatronics projects and reports. The projects cover analog and digital control of an inverted pendulum, motor documentation/demonstration, and an interactive potentiometer-controlled Pong game.

## Projects

| Project | Description |
|---|---|
| [Analog Inverted Pendulum Control](./Analog-Inverted-Pendulum-Control/) | Analog feedback controller for stabilizing an inverted pendulum using position sensing, velocity estimation, and a summing-amplifier control law. |
| [Digital Inverted Pendulum Control](./Digital-Inverted-Pendulum-Control/) | Digital PD controller for an inverted pendulum using Midori potentiometer feedback and myRIO-based implementation/tuning. |
| [Motor Demonstration Project](./Motor-Demonstration-Project/) | Early mechatronics project documenting the motor setup, team explanation, and motor demonstration. |
| [Potentiometric Pong](./Potentiometric-Pong/) | Interactive Pong-style mechatronics concept using potentiometers, Arduino, a NeoPixel display, servo feedback, and audio response. |
