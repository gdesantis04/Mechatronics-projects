# Digital Inverted Pendulum Control

Digital control-system project for stabilizing an inverted pendulum using Midori potentiometer feedback. The controller was implemented in software on a myRIO platform and tuned as a PD controller near the upright equilibrium.

## Main document

- [Digital Inverted Pendulum Control Report](./docs/Digital-Inverted-Pendulum-Control-Report.pdf)

## Project highlights

- Implemented a digital PD controller for an inverted pendulum.
- Used conditioned potentiometer feedback as the pendulum angle measurement.
- Tuned proportional and derivative gains to target damping and settling-time requirements.
- Compared underdamped, overdamped, and different sampling-frequency trials.
