# Potentiometric Pong

Interactive mechatronics game concept using potentiometer inputs to control a Pong-style display. The design combines sensing, computation, actuation, visual feedback, and audio feedback.

## Main document

- [Potentiometric Pong Poster](./docs/Potentiometric-Pong-Poster.pdf)

## Project highlights

- Potentiometers provide user input for paddle movement.
- Arduino handles sensing, computation, game logic, and display control.
- NeoPixel grid provides the visual game display.
- Servo motors and mechanical elements provide physical feedback.
- Piezo buzzer provides audio response for game events.
