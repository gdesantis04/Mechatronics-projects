# Analog Inverted Pendulum Control

Analog control-system project for stabilizing an inverted pendulum. The controller uses potentiometer-based position sensing, analog velocity estimation with a practical differentiator, and an inverting summing amplifier to implement the feedback control law.

## Main document

- [Analog Inverted Pendulum Control Report](./docs/Analog-Inverted-Pendulum-Control-Report.pdf)

## Project highlights

- Designed an analog feedback controller for an unstable inverted-pendulum system.
- Connected theoretical full-state feedback gains to physical resistor ratios and voltage scaling.
- Built and tested position, velocity, and control-summing circuits.
- Compared measured behavior with the nominal theoretical response.
